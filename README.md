# Customer Churn Analysis (Exploratory Data Analysis)

## Objective
To explore customer data and identify patterns and factors
that contribute to customer churn.

## Dataset
The dataset includes customer demographics, service usage,
and churn status.

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Correlation analysis between features and churn

## Key Findings
- Higher churn observed among customers with shorter tenure
- Certain service plans show increased churn probability
- Contract type strongly influences customer retention

## Business Recommendations
- Focus retention strategies on new customers
- Improve service offerings linked to high churn
- Promote long-term contracts to reduce churn
